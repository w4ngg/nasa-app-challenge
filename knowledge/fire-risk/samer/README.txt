SAME-R — Module 4 provisional package

Source files are unchanged.
CSV files use UTF-8 with BOM.

Start with:
- manifest.json: source fingerprint and record counts
- samer_working.csv: working results with provenance
- sts_all_17_with_chart_status.csv: all STS records and exclusions
- insights.json: provisional statements and limitations
- HTML files: interactive exploratory charts

Important:
- This package covers SAME-R, not the entire Module 4.
- Calculated diameters are not labeled direct measurements.
- Repeated/aged records are not assumed independent trials.
- STS delta is calculated as offset minus signal.
- No alarm threshold or detection probability is established.
- Charts must be displayed with the limitations in insights.json.
- Downloaded local files are not a substitute for original NASA
  source URLs/DOIs; add verified source links before publication.
